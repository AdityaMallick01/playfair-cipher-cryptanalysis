# Playfair Cipher Encryption and Cryptanalysis System

A web-based cybersecurity project implementing:
- Row-wise Playfair Cipher
- Column-wise Playfair Cipher
- Encryption & Decryption
- Dictionary-based Cryptanalysis
- Frequency Analysis
- Flask Web Interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Chart.js

## Features
- Secure message encryption
- Modified Playfair matrices
- Cryptanalysis simulation
- Frequency analysis graph
- Interactive web interface
